# GSE 测试用例库

本目录沉淀 GSE 节点管理与作业平台的测试用例，按业务模块分文件维护。

| 文件 | 模块 | 内容 |
| --- | --- | --- |
| [node.md](./node.md) | 节点管理 | 主机/接入点/Agent/Agent 配置台账、会话鉴权与存活探测、节点前端 |
| [job.md](./job.md) | 作业平台 | 作业执行/提交/查询、模板、历史作业重做、作业前端 |

## 用例编号规则

`<模块>-<层级>-<序号>`：

- 模块：`NODE`（节点）、`JOB`（作业）
- 层级：`EXEC`（执行器）、`SRV`（Server 逻辑）、`LEDGER`（台账）、`SESSION`、`CONFIG`、`TPL`（模板）、`RERUN`（重做）、`API`（HTTP 接口）、`E2E`（端到端）、`UI`（前端交互）、`ADAPTER`（适配器）

## 维护约定

- 新增或修改功能后，同步更新对应用例的「步骤/预期」与「自动化」列。
- `自动化` 列填写现有测试名；无测试的项目标为 `缺口`，并汇总到各文件末尾的「覆盖缺口」。
- 用例编号保持稳定，不复用已删除编号。
