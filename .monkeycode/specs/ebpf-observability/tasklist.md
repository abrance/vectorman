# 需求实施计划

本期只交付设计，本清单为待实施拆分，全部未开工。P1/P2/P3 是交付阶段，阶段间可独立上线；P3 未开工不影响 P1/P2。

实施顺序：本 feature 在 `apm-tracing` 之后（`LogStore` 索引 v2 → `dataplane-ts-retention` → `apm-tracing` → 本 feature）。服务名静态映射的 CRUD 由 `apm-tracing` 提供，本 feature 只消费。
